An eight-week learning path

For an experienced engineer, a few evenings per week. Each week ends with something you can play.

WeekGoalDoRead or watch
1The loopStarter project 1 (page 14): a dodge game in one HTML file with an agent. Add the debug overlay.Game Programming Patterns: Game Loop, Update Method; Fix Your Timestep!
2FeelStarter project 2: tune a platformer character until it feels good. Write down every number you changed.The "game feel" talks linked on page 7; Celeste's forgiveness article
3Levels and dataDraw three levels in Tiled or LDtk; have the agent write the loader and a validator.Red Blob Games (grids, pathfinding)
4TestingAdd the two test hooks and a Playwright smoke test per level (page 10).Playwright docs; OpenAI develop-web-game skill at its pinned commit
5Assets and soundSwap in a Kenney CC0 pack; generate effects with jsfxr; keep CREDITS.md.Kenney assets; page 1 and page 4
6ShipTitle screen, touch controls, itch.io upload, AI disclosure. Show five people.Page 12
7Try the other dimensionStarter project 4: the mini racer, or a small 3D scene in Three.js.Three.js manual
8Try an editorDo Godot's official first-game tutorial, then rebuild your week-6 game in Godot with an agent through an MCP server.Godot "Your first 2D game"

After week 8: join a game jam (itch.io jams, Ludum Dare, GMTK). A jam's fixed theme and deadline force scope discipline, which is the skill agents do not supply.

Red flags that you are off track

  • You have spent more time generating art than playing your game.
  • The agent has rewritten the movement code three times and it still "feels off": stop, tune the numbers yourself.
  • You cannot explain what a file does. Ask the agent to explain it, or throw it away and rebuild that part smaller.
  • Your scope list grows every week. Cut it in half; ship the half.
  • An autonomous run has used far more tokens than planned. Stop it, read what it did, set a limit.
