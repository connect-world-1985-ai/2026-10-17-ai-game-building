How to read the columns

GitHub stars
From the GitHub API on 2026-10-17. "—" means closed source, a hosted service, or a project not hosted on GitHub. Stars measure attention, not quality or usage.
Agent fit
The author's 0–3 rating of how well a coding agent can work with it: text files, command-line use, an API or MCP server, and how well current models know it. It is a judgment, not a measurement. Inference
Cost and licence
As stated on the vendor or licence page on 2026-10-17. Prices change often; check before paying.
Evidence
Label for the factual columns (licence, cost, stars). The "Best for" text is the author's summary.
