AI 3D: text or image to mesh, rigging, animation

Text-to-3D and image-to-3D services now return a textured model in under a minute for cents to tens of cents. The catch is what comes out: dense, triangulated meshes with lighting painted into the texture and no skeleton. This page covers the services, the open models, rigging, the quality gap for real-time games, and the procedural alternative that coding agents handle best.

Summary

For a first 3D game: build with code primitives (boxes, cylinders, extrusions) and CC0 kits (Kenney, Quaternius), animate humanoids with Mixamo, and use AI 3D only for static props you are willing to clean up. A generated asset costs cents; the real cost is the cleanup time. Inference based on the evidence below.

Start with code: procedural 3D

A language model writes three.js fluently. A car made of boxes and cylinders, trees made of cones, a track made from a spline: all of this is plain code, needs no files and carries no licence risk. The mini racer on page 9 is built exactly this way, with zero model files. Verified (our own demo)

Rigging and animation

A static mesh is not a character. To walk, it needs a skeleton, skin weights and animation clips.

Vehicles usually do not need a skeleton (wheels just rotate), which is one reason a racing game is easier in 3D than a creature game. Verified (humanoid-only) / Inference (racing remark)

The quality gap for real-time games

FindingEvidence
A practice-led study of a stylized tavern scene: AI-assisted pipeline (Meshy 6 + Hunyuan 3D) took 238 minutes versus 716 minutes by hand in Blender, but one AI scene had 32.8 million triangles for 103 objects against 294 thousand for 123 hand-made objects (about 111.6× more), plus fragmented UVs and texture loss when decimated.IJHRSSS 2026, one scene, not generalizable. Verified (results read)
Typical output: dense triangles, topology that follows appearance rather than deformation, lighting baked into the colour texture, internal faces and floating parts that differ between runs.AIGAMEDEV wiki, Wavect. Practice
Benchmarks of 3D generators rarely measure topology, UVs, rigs or engine import, so they "overestimate readiness".arXiv 2604.23629 survey. Verified
Vendors expose polycount controls: Tripo P1 face limit 50–20,000 "built for game assets"; Tripo quad mode; Meshy remesh.Vendor docs. Verified

A web or mobile game typically budgets thousands to low tens of thousands of triangles for an important prop. Default high-detail outputs are one to three orders of magnitude above that, so always set a face limit when the API offers one. Practice
