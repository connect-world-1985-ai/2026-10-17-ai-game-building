Sources and method

How this research was done, what the evidence labels mean, which assets the site bundles, what could not be settled, and every external source linked from the pages.

Method

  1. Scope and plan. The research questions came from the brief: assets, engines, fundamentals, two worked examples, testing, one-prompt claims, publishing and legal, a decision framework and hands-on projects.
  2. Fact gathering. Five research subagents each covered one area (AI images; AI 3D and audio; engines and libraries; examples, platforms and testing; publishing and legal) and wrote fact sheets with a source and a label for every claim. They were told to prefer primary sources and to record conflicts rather than resolve them silently.
  3. Verification by the main agent. The main agent re-checked the claims that matter most: GitHub star counts for 16 key repositories through the GitHub API (all within ±5 of the fact sheets), Simon Willison's Raccoon Heist post and repository, the Steam content survey, Gemini and OpenAI image pricing and features, Meshy's free-plan licence, itch.io HTML5 limits, YouTube video IDs, Kenney kit licences, and vehicle-physics APIs. This found one error that changed the pages: OpenAI's develop-web-game skill is not on the main branch.
  4. Judgment and writing. The main agent wrote every page, chose the recommendations and labelled them as Inference. Subagents wrote no page text.
  5. QA. Every page was loaded in a browser and checked for JavaScript errors, broken internal links and anchors, playable demos (driven by script through each demo's test hook), a 375 px mobile layout and file:// safety (no module imports, no fetching of local files).

All dates are 2026-10-17 unless stated. Prices, stars and terms change; re-check before relying on them.

Evidence labels

LabelUsed when
VerifiedA primary source confirms it: official docs, a repository or API, a paper, a court or agency document, or the person's own post. For "X says Y" claims it means X verifiably said it, not that Y is true.
PracticeWidely documented practitioner practice, a reputable secondary report, or a vendor demo with public artifacts that has not been independently reproduced.
InferenceThe author's analysis, recommendations and estimates.
UnverifiedA single weak source, a self-reported statistic, or a vendor or host claim ("Promotional").
ExperimentalWorks in research or demos, not yet dependable for shipping.
