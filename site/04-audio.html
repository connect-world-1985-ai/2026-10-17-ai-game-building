Audio: sound effects from code, music from somewhere else

Sound is the asset type where a coding agent is strongest on its own: retro sound effects are just a few oscillators and an envelope, which is ordinary code. Music is the opposite. This page shows the code route with a playable toy, then the AI services and free libraries, with the licence traps.

Sound effects from code

The classic tool is sfxr (DrPetter, 2007): a random generator for "jump", "coin", "laser" and "explosion" sounds built from a single oscillator, a pitch slide, noise and a volume envelope. Its descendants run in the browser and are small enough to paste into a game. An agent can either write a WebAudio synth directly or use one of these libraries. Verified

Try it: a procedural sound-effect generator

This toy is about 80 lines of WebAudio inside this site. Each sound is a small parameter object (wave type, start and end pitch, duration, noise, filter), exactly the kind of data an agent can write, tweak and store as JSON. Press a preset, then "Mutate" to get variations.

Interactive demo needs JavaScript.

Why this matters for agents: a sound defined as data can be reviewed in a diff, regenerated deterministically and tuned with words ("make the jump shorter and higher"). A WAV file cannot. The limit is style: these sounds are retro by nature, and realistic footsteps or a rich orchestral hit need samples or an AI model. Inference

Browser rule

Browsers block audio until the user interacts with the page, so create or resume the AudioContext on the first click or key press. MDN: Web Audio best practices Verified

Music

A language model can write a simple chiptune loop with Tone.js or a tracker-style pattern, which is fine for jam games. Memorable music is a different skill. The realistic options are free libraries, AI music services, or a composer. Inference

Copyright of AI-generated audio

The US Copyright Office concluded on 2025-01-29 that "prompts do not alone provide sufficient control" for authorship. A sound or song generated purely from a prompt may have weak or no US copyright, so others may be able to copy it. Your own arrangement and editing can be protected. Details on page 12. Verified

Recommended default

  1. Sound effects: code-synthesized (ZzFX or a small WebAudio synth like the toy above). Zero files, zero licence questions.
  2. Music: one CC0 or CC-BY track (Kenney, incompetech) with a proper credit, or a Tone.js loop the agent writes.
  3. Upgrade later: ElevenLabs or Stable Audio for specific realistic effects, on a paid plan, with the prompt and date recorded.
  4. Implementation: separate music and effects volume, limit how many copies of one effect play at once, and start audio on the first input.
