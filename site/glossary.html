Reference

Glossary

Game-development and AI-tool terms used on this site, explained for an engineer who knows software but not games.

TermAreaMeaning
AABBCollisionAxis-aligned bounding box: a rectangle (or box) that is not rotated. Two AABBs overlap when they overlap on every axis. The cheapest and most common collision test.
Agent (coding agent)AI toolsA language model that can act in a loop: read and write files, run commands, call tools, look at results and continue. Cursor, Claude Code and Codex are examples.
Arcade physicsPhysicsHand-written movement formulas tuned for fun rather than realism, as opposed to a physics engine.
Atlas (texture atlas)ArtOne image that packs many sprites or tiles, plus data describing where each one is. Fewer files and faster drawing.
Background removalArtCutting a character out of a generated image so it has a transparent background. Needed because many image models cannot output true transparency.
CC0LicencesCreative Commons "no rights reserved": use for anything, no credit required. Kenney's assets are CC0.
CC BY / BY-SA / BY-NC / BY-NDLicencesCreative Commons licences requiring credit (BY), plus share-alike (SA), non-commercial (NC) or no modifications (ND). NC and ND are poor fits for games.
CCDPhysicsContinuous collision detection: checks the path between frames, not just the end position, to stop fast objects passing through walls.
CLIAI toolsCommand-line interface. Many asset tools and engines can be driven from the command line, which is the easiest way for an agent to use them.
Code signingPublishingSigning a Windows program with a certificate so Windows can identify the publisher. Reduces, but no longer immediately removes, SmartScreen warnings.
Coyote timeGame feelA short grace period (about 0.1 s) after walking off a ledge during which a jump still works. Makes platformers feel fair.
Delta timeGame loopTime elapsed since the last frame. Movement multiplied by delta time runs at the same speed on any frame rate.
DeterministicTestingSame inputs always give the same result. Needs a fixed timestep and seeded random numbers; makes replays and automated tests reliable.
DMCA takedownLegalA US copyright notice asking a host to remove infringing material. Nintendo uses them against fan games.
ECSArchitectureEntity-component-system: entities are IDs, components are plain data, systems are functions over all entities with certain components. Used by Bevy and large games; optional for small ones.
Fixed timestepGame loopUpdating the simulation in equal steps (for example 1/120 s) regardless of the screen's frame rate, using an accumulator. Gives stable physics and determinism.
Game feel / juiceGame feelThe moment-to-moment sensation of control: responsiveness, acceleration curves, screen shake, particles, sound. Mostly tuned by playing.
Game loopGame loopThe repeating cycle of read input → update the world → draw. In browsers it runs on requestAnimationFrame.
glTF / GLB3DThe standard file format for 3D models on the web ("the JPEG of 3D"); GLB is the single-file binary form.
HeadlessTestingRunning a browser or engine without a visible window, typically in tests or CI. WebGL may render differently headless.
HitboxCollisionThe invisible shape used for collision, usually smaller than the sprite so near misses feel fair.
HTML5 gamePublishingA game that runs in a browser (HTML, JavaScript, Canvas or WebGL), uploaded as a ZIP with index.html.
Image-to-3D / text-to-3DAI toolsServices and models that produce a 3D mesh from a picture or a description (Meshy, Tripo, Hunyuan3D, TRELLIS). Output usually needs cleanup.
ImpressumLegalThe legally required provider identification on German websites, including non-commercial ones that are not purely private.
Jump bufferGame feelRemembering a jump press for a short time (about 0.1 s) before landing, so the jump happens on landing instead of being lost.
Kinematic bodyPhysicsAn object you move directly in code, which still collides, but is not pushed around by forces. Typical for player characters.
Live-generated contentLegalSteam's term for AI content created while the game runs (for example an LLM-driven character). Requires described guardrails. Opposite: pre-generated.
LOD3DLevel of detail: simpler versions of a model used when it is far away, to save rendering time.
MCPAI toolsModel Context Protocol: a standard for exposing tools (an engine editor, Blender, a browser) to an agent. The agent's host starts or connects to an MCP server and the model calls its tools.
Mesh3DA 3D shape made of vertices and triangles.
Nearest-neighbour scalingArtEnlarging an image by repeating pixels without blurring. Keeps pixel art crisp.
Normal map3DA texture that fakes small surface detail by changing how light hits each pixel.
Parallax2DBackground layers that scroll slower than the foreground to suggest depth.
PBR3DPhysically based rendering: materials described by colour, roughness and metalness so they look right under any light.
Physics enginePhysicsA library that simulates rigid bodies, forces and collisions (Box2D, Matter.js, Rapier, Jolt). Not needed for most platformers.
Pixel-native modelAI toolsAn image model or service trained to output real pixel art on a grid with a limited palette (for example PixelLab, Retro Diffusion), unlike general models that imitate the look.
Pre-generated contentLegalSteam's term for AI content made during development and shipped as files. Judged like any other content, and must be disclosed.
Procedural generationArtCreating content (levels, textures, sounds, meshes) with code and rules rather than by hand.
RaycastPhysicsShooting an invisible line to see what it hits. Used for ground checks, line of sight and vehicle wheels.
Raycast vehiclePhysicsA car model where the chassis is a rigid body and each wheel is a ray with a spring and friction.
Retopology3DRebuilding a messy mesh (for example from AI generation or scanning) with clean, efficient triangles that animate well.
Rig / rigging3DA skeleton inside a mesh so it can be animated. Auto-rigging tools (Mixamo, AccuRIG) work for humanoids only.
Scene graphArchitectureA tree of objects where children move with their parents (a wheel inside a car). Used by Three.js, Godot, Unity.
ShaderRenderingA small program that runs on the GPU to compute vertex positions or pixel colours.
Skill (agent skill)AI toolsA folder of instructions (usually SKILL.md) and scripts an agent loads to follow a specific workflow, such as "build and test a web game".
SmartScreenPublishingThe Windows feature that warns before running unknown downloaded programs.
Sprite / sprite sheetArtA 2D image of a game object; a sprite sheet holds several frames (for animation) in one image on a grid.
State machineArchitectureAn object that is in exactly one state (idle, run, jump, fall) with explicit rules for switching. Prevents contradictory behaviour.
TASLLicencesThe Creative Commons attribution checklist: Title, Author, Source, Licence.
Tile / tilemap2DA level built from a grid of small square images (tiles); the tilemap is the grid data. Edited in Tiled or LDtk.
Topology3DHow a mesh's triangles connect. Bad topology deforms badly when animated and wastes triangles.
TunnelingCollisionA fast object skipping through a thin wall because no frame caught it overlapping. Fixed with smaller steps, speed caps or CCD.
UV mapping3DHow a 2D texture is wrapped onto a 3D mesh.
Vibe codingAI toolsAndrej Karpathy's 2025 term for building software by prompting an AI and accepting its changes without reading the code; he scoped it to "throwaway weekend projects".
WebGL / WebGPURenderingBrowser APIs for GPU graphics. WebGL is supported everywhere; WebGPU is newer and faster but less universal.
World modelAI toolsAn AI model that generates an interactive video-like world frame by frame from user input (for example Genie, Matrix-Game). Not game code; hard to ship today.
