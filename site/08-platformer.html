Worked example: a side-scrolling platformer

"Make me a Mario game" is the most common first request. This page plans one properly: what to build (and what not to copy), which engine, where the art comes from under three strategies, the order to build it in with an agent, the parts that are hard, and honest time and cost ranges.

IP first: "Mario-like", not Mario

Game mechanics (run, jump, stomp, collect) are free to reuse; Nintendo's characters, names, sprites, sounds and level layouts are not. Courts protected Tetris's audiovisual expression while saying its rules are free (Tetris Holding v. Xio, 2012), and Nintendo regularly removes fan games with its characters. Do not prompt an agent or an image model with "Mario", and do not recreate World 1-1. Details on page 12. Verified

Scope: the smallest version worth making

Must have

One hero that runs and jumps with good feel; solid tiles; one enemy that walks and can be stomped; coins; pits; a goal flag; restart on death; a camera that follows.

Next

Three short levels from a level editor; a title screen and a win screen; sound effects; a timer or score; touch controls.

Later

Power-ups, moving platforms, a second enemy type, checkpoints, saving the best time, music.

Key design choices, each explained on page 7: fixed timestep; kinematic movement instead of a physics engine; axis-separated tile collision; explicit state machines; every tuning number in one config object; levels as data. Practice

Build order with an agent

  1. Skeleton. "Single index.html + game.js, Canvas 480×270 scaled with nearest-neighbour, fixed timestep 1/120 s, keyboard input map, a state machine with title/play/win, and a debug overlay toggled with F1." Run it.
  2. Movement feel. "Rectangle hero on a flat floor. Config object with acceleration, friction, gravity, jump speed, coyote time 0.1 s, jump buffer 0.12 s, variable jump height." Play it for ten minutes and tune the numbers yourself.
  3. Tiles and collision. "Level as a 2D array, axis-separated collision, debug hitboxes, unit tests for corner cases (landing on an edge, hitting a ceiling, walking into a wall)."
  4. Camera. Smoothed follow with look-ahead, clamped to the level bounds.
  5. Enemies, coins, pits, flag. One at a time, each with a test that uses a test hook such as window.__game.get().
  6. Levels from an editor. You draw levels in Tiled or LDtk; the agent writes the loader and a reachability validator that simulates the jump arc.
  7. Art pass. Swap the renderer to a CC0 pack. Then sound effects (page 4).
  8. Polish and ship. Title screen, touch controls, screen shake on stomp, a credits screen, an itch.io build (page 12).

Order follows the fundamentals on page 7 and the testing practice on page 10. Inference

The hard parts

ProblemTypical symptomFix
Jump feelFloaty or stiff; "eaten" jumps at ledgesCoyote time, jump buffer, higher gravity when falling, variable jump height. You must play and tune; the agent cannot feel it.
Tile collision edge casesSticking to walls, catching on tile seams, falling through at high speedResolve x then y; small step-up tolerance; cap fall speed below one tile per step
One-way platforms and slopesPopping through or jitteringSkip them in the first version; add with dedicated tests
Level designImpossible gaps or boring layoutsHuman-drawn levels; validator for reachability; one new idea per level
Enemy stomp vs hurtUnfair deaths when landing on an enemyCount a stomp if the hero is moving down and its feet were above the enemy's centre last step
Frame-rate dependenceGame runs twice as fast on a 120 Hz screenFixed timestep; test with the loop toy on page 7

Time and cost, honestly

No study measures how long agent-assisted platformers take. The ranges below are the author's estimates for an experienced engineer who has never made a game, working with a current coding agent. Treat them as a planning guess, not data. Inference

MilestoneEstimateWhat eats the time
First playable (moving, jumping, one level, shapes)1–3 hoursSetting up the loop and tuning movement
"Must have" scope with good feel1–2 daysFeel tuning, collision edge cases, playtesting
Three designed levels, CC0 art, sound, shipped on itch.io1–2 weeks of eveningsLevel design and polish, not code
Unique AI-generated art setAdd several daysPipeline, cleanup, curation, consistency

Money: a coding-agent subscription you probably already have, plus $0 for strategies A and B, or a few dollars of API calls for strategy C (see the derived prices above).
