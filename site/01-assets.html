Where the art and audio come from

A coding agent writes text. A game also needs pictures, animation, 3D models, sound effects and music. This page sorts every realistic source into five families, says exactly what a language model can produce on its own, and shows how an agent reaches the tools that produce the rest. The demo lets you switch the same level between three art strategies.

The short answer

A language model on its own outputs text: code, SVG, shader source, JSON, pixel grids written as numbers. With that it can draw simple shapes, icons, UI, procedural textures and synthesized sound, all from code. Anything that needs real pixels or audio samples (painted sprites, textured 3D models, recorded or generated music) comes from a file you download or from another model the agent calls through an API, an MCP server or a command-line tool. Verified for the "text only" part (that is what these models emit); the rest is Practice.

Shapes (code-drawn)

Rectangles, circles and a few lines. Zero files, zero licence questions, fully readable by an agent. Looks "programmer art", but it is consistent, and every gameplay object is clearly distinguishable.

Emoji

One character per object. Instantly charming, but sizes and styles vary across Windows, macOS and Android, and you cannot animate a single emoji's legs.

Sprites (CC0 pack)

Kenney's Pixel Platformer pack, public domain (CC0). A coherent look made by one artist. The agent only had to read the atlas layout and pick tile indices.

Why is there no "AI-generated" mode? Bundling AI images would need an image-API key and would make the site depend on a paid service; it would also show only one lucky result. How an agent gets access to tools

Claude Code, Codex and Cursor can all run shell commands and edit files. That is enough to reach almost any asset tool. There are four ways, from simplest to most packaged:

Cost guard

Several APIs offer a free price check before generating: Ideogram dry_run, Retro Diffusion check_cost, Scenario dryRun, fal get_pricing. Tell the agent to price a batch before running it, and set a spending limit on every API key. Verified (features in vendor docs)

Practical rule for agents

Put this in the project's agent rules: "Every time you add an asset or dependency, append a row to CREDITS.md with name, author, source URL, licence and date. Never add CC-BY-NC, CC-BY-ND or GPL items without asking." Agents can download from the libraries above, but licence fields differ per item, and agents do not report licences unless told to.
